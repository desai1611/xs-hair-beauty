# Videos

Put the Hair Services promo video here as **`hair-promo.mp4`**. The page picks it up
automatically: it plays silently on a loop, and visitors can tap "Sound" to hear it.

- Use MP4 (H.264), about 720p, ideally under 8 MB and 10-30 seconds.
- If the file is missing, the page shows a photo with a play button linking to the
  salon's Instagram instead.
- A YouTube link can also be set in the admin dashboard (Site content > hair promo video),
  which takes priority over this file.
- Only use footage you have the right to use. Pexels videos are free for commercial use
  (https://www.pexels.com/license/); keep a note of the clip URL here.
